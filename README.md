# Home-Based SOC Lab — Security Monitoring and Incident Detection

A hands-on cybersecurity project focused on building and operating a home-based Security Operations Center (SOC) environment using Wazuh, Sysmon, Windows, Ubuntu Server, VMware, and Kali Linux.

The project demonstrates practical skills in security monitoring, endpoint telemetry, threat hunting, alert investigation, event correlation, and incident analysis.

---

##  Project Objectives

- Build a functional home SOC environment
- Deploy and configure Wazuh for security monitoring
- Monitor a Windows endpoint using the Wazuh Agent
- Collect detailed endpoint telemetry using Sysmon
- Investigate security alerts generated by Wazuh
- Perform threat hunting using endpoint events
- Analyze Windows processes and parent-child relationships
- Investigate command lines, process IDs, hashes, and timestamps
- Correlate events to build investigation timelines
- Apply MITRE ATT&CK concepts during investigations
- Document findings as a professional cybersecurity project
